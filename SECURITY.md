# Security Policy

## Supported Versions

Currently, only the latest main branch and the most recent major release are actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

Because Quiz Forge is an entirely client-side application (Zero Backend), the primary security vectors involve XSS (Cross-Site Scripting) or vulnerabilities within our npm dependencies.

If you discover a security vulnerability within Quiz Forge, please do **NOT** open a public issue.

Instead, please send a private message to the maintainer or use the GitHub Security Advisory feature:

1. Go to the Security tab of this repository.
2. Click on Report a vulnerability (if enabled) or reach out via email.

Please include:

- A description of the vulnerability.
- Steps to reproduce the issue.
- Any possible mitigations.

We take security seriously and will attempt to respond to all reports within 48 hours. Fixes will be pushed as part of a patch release.
