**Summary:**
Optimized the date string generation loop in the activity heatmap.

**Motivation:**
In `buildHeatmapData`, the loop decremented the date on a single object and then called `getLocalYYYYMMDD()`. `getLocalYYYYMMDD()` generates an extra `Date` instance for offset subtraction and runs `toISOString().split('T')[0]`. By extracting year, month, and day components directly from the loop's `Date` instance and using string interpolation, we skip this extra instantiation and substring allocation entirely.

**Benchmarks & Metrics:**
In 10,000 iterations over a 728 day heatmap range:
- Baseline (Original Code): ~12851ms
- Optimized String construction: ~4737ms
(Around a ~2.7x speedup for this segment)

Ran `pnpm run test:run` and visually verified the UI with Playwright screenshots. Tests pass and behavior is identical.
